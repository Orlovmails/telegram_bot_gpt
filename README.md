# 🤖 Потужний Мультимодальний Помічник ChatGPT Telegram Bot

Цей Telegram-бот поєднує в собі асинхронні можливості бібліотеки `python-telegram-bot` та нейромережеві моделі OpenAI (`gpt-4o-mini`).

## 🚀 Функціонал
1. **Головне меню** — зручна навігація за допомогою Reply & Inline кнопок.
2. **🧠 Випадковий факт** — генерація унікальних цікавих фактів через ШІ.
3. **🤖 Чат з GPT** — прямий інтерфейс спілкування з ШІ у режимі реального часу.
4. **👤 Розмова з особистістю** — рольова гра з відомими людьми (Курт Кобейн, Стівен Гокінг та ін.).
5. **❓ Інтерактивний Квіз** — перевірка знань з різних тем з автоматичним підрахунком балів.
6. **📸 Розпізнавання зображень (Vision)** — аналіз та детальний опис надісланих користувачем фотографій.
7. **📝 Конструктор резюме** — покрокове опитування користувача з подальшим очищенням та генерацією професійного резюме в HTML-форматі.

## 🛠 Технологічний стек
- Python 3.10+
- python-telegram-bot (v20.x, Async)
- OpenAI API (GPT-4o-mini, мультимодальні запити)
- Python-dotenv (безпечне збереження токенів)
- Logging (відстеження стану системи)

## 💻 Як запустити локально
1. Клонуйте репозиторій.
2. Створіть файл `.env` у корені та додайте ваші `BOT_TOKEN` та `CHATGPT_TOKEN`.
3. Встановіть залежності: `pip install -r requirements.txt`
4. Запустіть бота: `python bot.py`
